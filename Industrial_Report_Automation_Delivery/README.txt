Industrial Report Automation
============================

How to Start:
1. Double-click "Industrial Report Automation.exe".
2. Wait for the application to start.
3. The application will open in your default web browser.
4. Upload the required XPS file.
5. Preview the extracted data.
6. Generate the Excel report.

Important:
- Windows computer required.
- Python and VS Code are not required.
- Do not close the application while processing files.
